Asal çarpan bulma

Bir sayının asal çarpanlarını bulun. Notebook testleri her çarpanı yalnızca bir kez bekler: 2025 = 3⁴ · 5² için sonuç [3, 5] olmalıdır.

Zorlanırsanız önce şu temel konulara bakın: Operatörler, Listeler, while, break ve continue, Fonksiyonlar.

Çözüm

from typing import List

def prime_factors(n: int) -> List[int]:
    """n sayısının farklı asal çarpanlarını döndürür."""
    factors = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            factors.append(d)
            while n % d == 0:
                n //= d
        d += 1
    if n > 1:
        factors.append(n)
    return factors

def flatten_list(nested_list):
    """İç içe listeyi sırayı koruyarak düz listeye çevirir."""
    result = []
    for item in nested_list:
        if isinstance(item, list):
            result.extend(flatten_list(item))
        else:
            result.append(item)
    return result

Problem 4 / 6

Verilen ortalamada liste oluşturma

Eleman sayısı n, hedef ortalama ve açıklık (max − min) verilen bir liste üretin. Tek bir doğru yanıt yoktur; üç koşulu sağlayan her liste geçerlidir.

Çözüm

def generate_mean_list(n, mean, range_width):
    """n elemanlı, ortalaması mean, açıklığı range_width olan bir liste üretir."""
    if n < 1:
        raise ValueError("n en az 1 olmalı")
    if range_width < 0:
        raise ValueError("açıklık negatif olamaz")
    if n == 1:
        if range_width != 0:
            raise ValueError("Tek elemanlı listenin açıklığı 0 olmalı")
        return [mean]
    half = range_width / 2
    return [mean - half, mean + half] + [mean] * (n - 2)

Problem 5 / 6

Sınıf ortalaması hesaplama

Not listesinden geçersiz değerleri ve aykırı uçları ayıklayarak "stabil ortalamayı" hesaplayın.

Zorlanırsanız önce şu temel konulara bakın: Listeler, Comprehension, enumerate ve zip, if, elif, else, Hata yakalama ve import.

Çözüm

from statistics import mean, pstdev

def calculate_mean(l: list[int]) -> float:
    """Geçersiz ve aykırı notlar dışarıda bırakılarak stabil ortalamayı döndürür."""
    valid = [x for x in l if 0 <= x <= 100]
    if not valid:
        return 0.0
    m, s = mean(valid), pstdev(valid)
    stable = [x for x in valid if m - s <= x <= m + s]
    return float(mean(stable))

def time_diff(time1: str, time2: str) -> int:
    """time1'den time2'ye ileri doğru geçen dakika (gece yarısını aşabilir)."""
    h1, m1 = map(int, time1.split(":"))
    h2, m2 = map(int, time2.split(":"))
    return ((h2 * 60 + m2) - (h1 * 60 + m1)) % 1440
